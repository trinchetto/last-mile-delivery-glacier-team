# Pandas AI tool

## Instructions:
1) Install the libraries as stated in requirements.txt
2) get the open router API key to access the LLMs provided by the hackathon organizers

3) Open run_tabular_assistant.py and paste the api key on line 6
    api_key="API GOES HERE"
4) you can test run_tabular_assistant.py
   Notice that this script initializes a class of the type: **TabularAssistant**

## Brief explanation:
The flow of this tool is as follows:
1) **Prompt analysis**: Uses the sematic information associated with the data to rewrite the input prompt in such a 
   way pandasai can better understand it.
   *Examples*
   input_prompt: Which carriers are the most reliable?
   output: Create a table of the top 3 carrier by the number of unique load_id_pseudo with otd_designation equal to "On-Time" or "Delivered Early". 
2) **PandasAI search**: This step will run pandasai using the input from the prompt analysis.
3) **Answer explanation**: Uses the code generated by pandas ai, the user prompt and the generated code to explain the answer provided by pandasai.


## Output provided by the tool:

A dictionary with the following fields:
* **prompt_analysis**: The output from the prompt_analysis chain.
* **output**: The raw output from pandasai, given as markdown string.
* **code_executed**: The generated/executed code by PandasAI.
* **explanation**: The answer explained, given as a markdown string.
* **image_path**: In case an image/chart was generated, it will return a path to the image, otherwise *None*
